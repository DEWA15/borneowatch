Hubungkan NASA FIRMS

Untuk mengaktifkan titik panas satelit VIIRS yang lebih rinci, gunakan MAP_KEY gratis NASA FIRMS atau impor file CSV dari NASA. Data yang diimpor hanya digunakan di browser ini.

CSV harus memiliki kolom latitude dan longitude. Data dibatasi ke kotak pemantauan Kalimantan. Pilih file terbaru untuk hasil relevan.

Opsi 2 — Akses langsung memakai MAP_KEY

Daftar di halaman kunci API NASA. Browser tertentu memblokir akses lintas asal (CORS); bila gagal, gunakan impor CSV.

Jangan masukkan kunci API milik layanan AI berbayar ke HTML publik. Kunci NASA hanya dipakai di browser pengguna.
